# 📚 BookBazaar

BookBazaar is a full-stack web-based buy-and-sell platform designed for book lovers to browse, purchase, and sell books online.

---

## 🚀 Features

- User authentication
- Browse books
- Search functionality
- Add to cart
- Seller dashboard
- Responsive design

---

## 🛠️ Technologies Used

- React
- Vite
- Tailwind CSS
- Supabase
